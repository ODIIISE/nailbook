## Dead ends
- Fresha's main marketing pages return JavaScript-rendered shells with no extractable text content (SPA rendering blocks web scraping).
- Booksy's blog URLs have inconsistent path structures; many expected 404s before finding the correct `/en-us/` path format.
- Vagaro's support/help center DNS did not resolve from this environment (SSRF protection triggered).
- Fresha's help center article for online booking setup returned a generic landing page rather than step-by-step flow documentation.

## Suggested follow-ups
- Analyze the actual end-to-end booking UI flows of each platform via screen recording or prototype teardown (the marketing pages describe features but don't reveal exact screen-by-screen flow).
- Investigate conversion rate benchmarks: what is the industry-standard drop-off rate between service selection and booking confirmation across these platforms?
- Research Persian/Iranian salon booking apps (Tapsi, Snapp, local competitors) to understand cultural UX expectations (RTL layout, Farsi naming conventions, local payment methods).
