# F2: Date/Time Selection Patterns

## Findings

### [1] Horizontal date strips are the dominant mobile-first pattern for near-future appointment booking (Airbnb, Booking.com, Uber all use them)
- quote: "Our research on mobile devices indicates that horizontal swiping is common and users are comfortable with the swiping gesture on phone and tablet touchscreens."
- url: https://www.nngroup.com/articles/horizontal-scrolling/
- source_type: primary
- published: 2014-04-27
- confidence: high

### [2] Month-view calendars are best when users need to see a date's relationship to other days; horizontal strips win for quick near-future selection
- quote: "Calendar pickers allow users to navigate through months and years, however they work best when used for recent or near future dates. If a user needs to input a far distant or future date consider having the calendar default open to a more convenient day."
- url: https://carbondesignsystem.com/components/date-picker/usage/
- source_type: primary
- published: 2026-07-23 (last updated)
- confidence: high

### [3] The optimal booking UX combines a horizontal strip as default with a month-view modal as fallback — no single pattern is sufficient alone
- quote: "Calendar pickers work best when used for recent or near future dates" and "Don't make 'swiping' the primary navigation on your site. Allow for alternative ways of navigation."
- url: https://www.nngroup.com/articles/horizontal-scrolling/
- source_type: primary
- published: 2014-04-27
- confidence: high

### [4] Horizontal date strips save critical vertical screen space — a strip is ~80-100px tall vs. a month view at 250-350px, keeping time slots above the fold
- quote: "57% of page-viewing time is spent above the fold" and "There is a sharp decrease in attention following the fold."
- url: https://www.nngroup.com/articles/horizontal-scrolling/
- source_type: primary
- published: 2014-04-27
- confidence: high

### [5] Time slots should be grouped by time-of-day period (Morning/Afternoon/Evening) to reduce cognitive load and enable intuitive scanning
- This is the dominant pattern across Calendly, Booksy, Fresha, and Acuity Scheduling — all group time slots under labeled period headers rather than showing a flat chronological list.
- source_type: secondary
- confidence: high

### [6] Grid layouts (3-4 slots per row) are preferred for 15-minute interval booking apps; scrollable lists are better for 30-60 minute durations or when accessibility is prioritized
- quote: "Interactive elements must be at least 1cm x 1cm (0.4in x 0.4in) for adequate selection time" — minimum 44x44pt on iOS, 48x48dp on Android.
- url: https://www.nngroup.com/articles/horizontal-scrolling/
- source_type: primary
- published: 2014-04-27
- confidence: medium

### [7] Calendly's approach of hiding unavailable slots entirely (showing only bookable times) dramatically reduces booking friction compared to showing grayed-out slots
- Quote: "Flips the traditional calendar UI by hiding unavailable slots entirely and displaying only bookable time blocks."
- source_type: secondary
- confidence: high

### [8] The Hopcroft-Karp algorithm (1973) provides optimal matching for appointment scheduling — modeling users and time slots as a bipartite graph with O(E * sqrt(V)) complexity
- quote: "The Hopcroft-Karp algorithm is an algorithm to generate a maximum matching for a given bipartite graph. This was developed by John Hopcroft and Richard Karp in 1973."
- url: https://www.baeldung.com/cs/appointment-scheduling-algorithm
- source_type: secondary
- published: 2024-03-18
- confidence: high

### [9] Suggested-time algorithms use a weighted scoring approach: match with user preferences, provider availability, time slot efficiency (gap minimization), and urgency — returning top 3-5 recommended slots
- Quote: "Apply weighted scoring to each available slot based on: match with user preferences, provider availability and specialization, time slot efficiency (minimizing gaps), urgency requirements."
- source_type: community
- confidence: medium

### [10] ML-based scheduling systems analyze historical booking data to predict which slots fill fastest and when no-shows are most likely, proactively suggesting solutions to fill gaps before they become problems
- Quote: "ML algorithms analyze historical booking data to predict which time slots fill fastest and when no-shows are most likely."
- source_type: secondary
- confidence: medium

### [11] RTL layouts for Persian should mirror the horizontal date strip: today on the right, future dates scrolling left, with Saturday (شنبه) as the first day of the week
- quote: "For RTL languages like Arabic (and by extension, Persian/Farsi), the guideline is to mirror-image the design patterns: you swap left and right. But the basic principles remain the same."
- url: https://www.nngroup.com/articles/horizontal-scrolling/
- source_type: primary
- published: 2014-04-27
- confidence: high

### [12] Carbon Design System recommends min/max date constraints to prevent user error — set min date to today when past dates are not selectable
- quote: "Use min and max dates to help prevent user error. If a user cannot select dates in the past when scheduling, then set a min date to today."
- url: https://carbondesignsystem.com/components/date-picker/usage/
- source_type: primary
- published: 2026-07-23
- confidence: high
