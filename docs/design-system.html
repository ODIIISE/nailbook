یک پالت گرم، دو تم، صفر حرکت — و یک استثنای لوکس

این صفحه آینه‌ی چیزی که واقعاً پیاده‌سازی شده است — نه چیزی که باید باشد. همه‌ی مقدارها ۱:۱ از globals.css، design-tokens.ts و lux-home.module.css کپی شده‌اند. روی هر سواچ کلیک کنید تا مقدار آن کپی شود.

Warm atelier (light + dark) for the whole app · Lux espresso/gold as a scoped homepage exception · Estedad FD typography · Persian-first RTL.

۰۱

رنگ — آتلیه گرم

SEMANTIC TOKENS

یک پالت معنایی برای کل اپ (به‌جز صفحه اصلی لوکس). توکن معنایی همیشه — رنگ خام در کامپوننت ممنوع. با کلید تیره‌ی بالا، کل جدول را در تم اسپرسو هم ببینید.

قاعده‌ی متغیر-اول: همیشه bg-primary، text-muted-foreground، border-border — هرگز bg-white یا text-black خام. تم تیره فقط با کلاس .dark روی <html> و از طریق همین توکن‌ها کار می‌کند.
۰۲

تایپوگرافی — استعداد FD

TYPE SCALE

یک فونت: Estedad FD (وزن متغیر ۱۰۰–۹۰۰، ارقام فارسی) از CDN با preload. فونت لاتین نمایشی ممنوع — «فورهند» با همین فونت نوشته می‌شود. font-synthesis: none سراسری است (ایتالیک ساختگی ممنوع). ارقام لاتین/کدها داخل dir="ltr".

BUTTONS

استثنای لوکس — صفحه اصلی

۱۰

سیاست حرکت

MOTION POLICY

بقیه‌ی اپ — صفر حرکت

تغییر حالت‌ها فوری‌اند. این یک انتخاب برند است، نه محدودیت فنی.
  • ممنوع: transition · animation · animate-* · framer-motion · drag/swipe
  • مجاز: بازخورد لمسی (haptics) — فیدبک است نه حرکت
  • نیروی قانون: no-motion.test.ts بیلد را می‌شکند

صفحه اصلی لوکس — حرکت تأییدشده

فقط transform/opacity؛ رندر با کاهش-حرکت کاربر محترم است.
  • اسلایدشو: فریم ثابت ۵:۶ + object-fit:cover، اتوپلی که به تعامل کاربر تن می‌دهد
  • ورود یک‌باره (choreography) سپس توقف — حلقه‌ی بی‌پایان فقط: رینگ مداری + درخشش CTA
  • پاسخ به ارتفاع: کلمپ‌های dvh — چیدمان مرجع ۸۴۴px پیکسل‌به‌پیکسل حفظ می‌شود

۱۲

قواعد طلایی

DO & DON'T

بکن ✅

  • توکن معنایی — همیشه
  • خصوصیت منطقی (ps/pe/ms/me/start/end) — هرگز فیزیکی
  • ارقام فارسی + تاریخ جلالی؛ dir="ltr" برای شماره/زمان
  • هدف لمس ≥ ۴۴px، فوکوس‌رینگ، Escape روی همه‌ی لایه‌ها
  • قبل از UI جدید: اول دیتاستیت‌ها (خالی/بارگذاری/خطا/جزیی)
  • چک نهایی: npm run check + بررسی واقعی ۳۹۰px و ≥۱۲۸۰px، هر دو تم، بدون خطای کنسول

نکن ❌

  • هگز خام در کامپوننت (فقط در design-tokens.ts برای دیتا)
  • حرکت خارج از LuxHome — تست گیت اجازه نمی‌دهد
  • فونت لاتین نمایشی در اپ اصلی
  • کارت داخل کارت؛ سایه‌ی رنگی در تم تیره
  • استایل لوکس بیرون از lux-home.* — نشت ممنوع
  • ویژگی قلابی: toast الکی، «به‌زودی»، دیتای نمایشی hardcode شده
